# calculadorac.com

Calculadora online gratis para Argentina: calculadora estándar y científica, porcentajes, IVA, sueldo neto, aguinaldo y regla de tres. Rápida, precisa, sin registro y 100% privada.

🌐 Sitio web: https://calculadorac.com/

## Herramientas

- Calculadora online (estándar y científica)
- Calculadora de porcentajes
- Calculadora de IVA Argentina
- Calculadora de sueldo neto
- Calculadora de aguinaldo
- Calculadora científica
- Regla de tres

Todo el sitio es HTML estático, sin frameworks, alojado en GitHub Pages.
